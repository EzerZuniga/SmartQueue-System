---
description: Comandos para aplicar estilos de escritura y verificar errores en el código
---

Ejecuta:
- npm run lint
Debes asegurarte que no haya ninguna advertencia de error, si hubiera alguna tienes que corregirlo

- npm run format
Es para aplicar formato al código de JS

- composer pint
Es para aplicar formato a las clases y metodos de PHP
